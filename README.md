# MCC 2026 ROMS 优化实验仓库

本仓库用于记录 MCC 2026 决赛中 ROMS-CoSiNE15 模型的代码修改、编译配置、实验脚本与性能优化过程。

## 项目结构

```text
MCC-Final-SYSU/
├── ROMS_CoSiNE15/   # 比赛提供的 ROMS 源码；作为优化前的代码基线
├── Local_Lab/       # 本地构建配置、测试脚本和实验记录
│   ├── configs/     # 可复用的 ROMS 输入配置
│   ├── overlays/    # 与官方源码分离的替换或扩展代码
│   ├── builds/      # 编译中间文件（不纳入 Git）
│   ├── bin/         # 可执行文件（不纳入 Git）
│   └── runs/        # 本地运行目录；日志和模型输出不纳入 Git
├── vali.py          # 主办方提供的结果验证程序
└── sub.sh           # 参考运行脚本
```

大型 NetCDF 输入数据、模型输出、编译产物、Conda 环境和原始压缩包不会提交到 Git。克隆仓库后，需要单独将比赛数据放回 `ROMS_CoSiNE15/Inputfiles/`。

## 当前基准

- 编译应用：`BYE24BIO15`
- 模型输入：`ROMS/External/ocean_SCS_Dongsha60_bio15.in`
- 完整任务：外层网格 `2592` 步、内层网格 `12960` 步，对应三天模拟
- 官方示例分块：两个网格均为 `NtileI=4`、`NtileJ=8`，对应 32 个 MPI 进程
- 本地一步冒烟测试：单 MPI 进程正常退出，峰值内存约 5.66 GiB

## 工作约定

1. 保留比赛源码作为初始基线，用 Git diff 记录后续优化。
2. 测试配置、脚本和 profiler 辅助代码放在 `Local_Lab/`。
3. 编译文件、运行日志和 NetCDF 数据不提交。
4. 每次性能实验记录编译器、编译参数、MPI 进程数、网格分块、运行时间和验证结果。
5. 最终结果必须使用完整三天配置，并通过主办方的 `vali.py` 精度验证。

## 注意

比赛源码和验证程序可能受赛事发布规则约束。在确认允许公开之前，GitHub 仓库应设置为 **Private**。
